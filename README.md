# Raven61 Web Driver

Raven61 홀 이펙트 키보드용 브라우저 기반 설정 도구입니다. WebHID로 보드에 직접 붙기
때문에 설치가 필요 없고, 순정 윈도우 드라이버 없이 크롬/엣지에서 바로 동작합니다.

> **브랜치:** 이 `dev` 브랜치는 **작업 중인 전부**입니다 — 리버스 엔지니어링 도구,
> 분석 스크립트, 아직 프로토콜이 해독되지 않은 설정 패널까지 포함합니다.
> `main` 은 완성되어 실제로 동작하는 것만 담습니다 (장치 연결 + 모니터).
> 기능이 완성되면 `dev` 에서 `main` 으로 올립니다.
> `main` 은 <https://sufl3770.github.io/Raven61WebDriver/> 에 자동 배포됩니다.
> 이 브랜치는 배포되지 않으므로 로컬에서 실행해야 합니다.

> **현재 상태:** 읽기 쪽은 끝났고, 남은 것은 **설정 쓰기 명령의 데이터 배치**입니다.
>
> 순정 드라이버 분석으로 확인된 것:
>
> - 장치 **VID `0x19F5`**, PID `FE20` / `FED0` / `FEB1`, USB 인터페이스 `MI_01`
> - 통신은 **OUTPUT / INPUT 리포트** (`WriteFile` / `ReadFile`), 65바이트, 리포트 ID 0
> - **패킷 프레임**: 매직 `0x55`, 명령, 합 체크섬, 응답은 요청의 에코(`0xaa`)
> - **블록 전송**: 길이 + 오프셋(LE16) + 56바이트 청크
> - **명령 13종**: `0x01` 시작 → 작업 → `0x02` 종료·적용
> - **아날로그 키 이벤트** 완전 해독 — 61키 전부 식별, 실시간 모니터가 동작합니다
> - 61키 전부의 **펌웨어 키 주소**(`keyIndex`) 와 수정자 식별표
> - 값 인코딩 **1 카운트 = 0.02 mm**, 총 스트로크 **4.00 mm**
> - 설정 데이터 모델, 레이어 4개, 프로파일 3개, 고급 키 6종
>
> 자세한 내용은 [docs/protocol.md](docs/protocol.md).

## 실행

```bash
npm install
npm run dev
```

크롬, 엣지, 오페라 **데스크톱** 에서 열어야 합니다 (WebHID 필요). 파이어폭스와 사파리는
WebHID를 지원하지 않습니다.

## 탭 구성

**설정 패널** — 모니터만 동작하며, 나머지는 프로토콜이 해독되면 활성화됩니다.

| 탭 | 내용 |
|----|------|
| 장치 | 연결(VID 0x19F5 프리셋), 인터페이스 선택, 설정 채널 후보 점수 |
| 액추에이션 | 키별 작동 깊이, 프리셋 일괄 적용 |
| 래피드 트리거 | RT 켜기/끄기, 누름·뗌 민감도(분리 가능), 연속 모드, 데드존 |
| 모니터 | **동작** — 실시간 키 깊이, 트레이스 그래프, 노이즈 측정 |
| 키맵 | Main + FN 1–3, 총 4레이어 키코드 배정 |

**분석 도구** — 지금 바로 쓸 수 있습니다.

| 탭 | 내용 |
|----|------|
| 탐색기 | 리포트 디스크립터 트리, 사용 가능한 리포트 ID와 길이 |
| 콘솔 | 프레임/블록 형식으로 명령 송신, 반복 전송 후 변하는 바이트 표시 |
| 프로버 | 실제 프레임(체크섬 자동)으로 명령을 스윕하고 응답 확인 |
| 이벤트 | 보드가 올려보내는 리포트 수신 + 센서 주소 연결 (전송 없음, 안전) |
| 로그 | 모든 송수신 기록, A/B 바이트 diff, TXT·JSON 내보내기 |

## 프로토콜 작업

- 캡처 절차와 방법론: [docs/reverse-engineering.md](docs/reverse-engineering.md)
- 알아낸 내용 기록: [docs/protocol.md](docs/protocol.md)
- 명령 표 추출 (정적 분석): `python tools/bin/commands.py "<순정 드라이버>/Raven Driver.exe"`
- 순정 DB 읽기/비교: `python tools/db/extract.py a.db --diff b.db`
- 런타임 추적: `frida -f "Raven Driver.exe" -l tools/frida/trace-hid.js`
- 캡처 변환/비교: `node tools/pcap/extract.mjs --diff a.pcapng b.pcapng`
- 레이아웃 재생성: `node tools/layout/from-vendor-xml.mjs "<순정 드라이버>/layouts/Raven61.xml"`

순정 드라이버 파일 자체는 재배포 대상이 아니므로 `.gitignore` 에 넣어 두었습니다.
로컬에 두고 위 생성기로만 참조합니다.

해독한 명령은 `src/protocol/` 에 `Raven61Codec` 구현으로 추가하고
`src/protocol/registry.ts` 의 `CODECS` 맨 앞에 등록하면 됩니다. 구현한 메서드만큼 UI가
자동으로 열립니다.

## 구조

```
src/
  hid/         WebHID 전송 계층 — 장치 핸들, 리포트 길이, 요청/응답 대응, 트래픽 로그
  protocol/    패킷 프레임, 이벤트 디코더, 코덱 인터페이스, 도메인 모델
  keyboard/    Raven61 61키 배열, HID 키코드 표, 수정자 식별표
  state/       연결·설정·선택 스토어
  tools/       리버스 엔지니어링 UI
  features/    설정 UI
```

## 라이선스

Apache-2.0. 자기 소유 기기의 상호운용성 확보를 위한 프로젝트이며, 순정 드라이버의 코드나
바이너리는 포함하지 않습니다.
