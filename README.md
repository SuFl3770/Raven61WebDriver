# Raven61 Web Driver

Raven61 홀 이펙트 키보드용 브라우저 기반 도구입니다. WebHID로 보드에 직접 붙기 때문에
설치가 필요 없고, 순정 윈도우 드라이버 없이 크롬/엣지에서 바로 동작합니다.

이 브랜치(`main`)는 **완성되어 실제로 동작하는 기능**만 담고 있습니다.

설치 없이 바로 쓰려면 **<https://sufl3770.github.io/Raven61WebDriver/>** 를 열면 됩니다.
`main` 에 푸시할 때마다 GitHub Actions 가 이 페이지를 다시 배포합니다.

| 탭 | 내용 |
|----|------|
| 장치 | 연결, 인터페이스 선택, 설정 채널 후보 점수 |
| 모니터 | 실시간 키 깊이, 트레이스 그래프, 정지 시 노이즈 측정 |

설정 쓰기(액추에이션 · 래피드 트리거 · 키맵)는 아직 프로토콜이 해독되지 않아
`dev` 브랜치에서 리버스 엔지니어링 도구와 함께 작업 중입니다.

## 실행

```bash
npm install
npm run dev
```

직접 빌드해서 열 때도 경로에 상관없이 동작합니다 (`base: ''`).

크롬, 엣지, 오페라 **데스크톱**에서 열어야 합니다 (WebHID 필요). 파이어폭스와 사파리는
WebHID를 지원하지 않습니다.

**장치** 탭에서 `Raven 계열 (VID 0x19F5)` 프리셋으로 연결한 뒤 **모니터** 탭에서 시작하면
됩니다. 순정 드라이버가 실행 중이면 장치를 잡고 있을 수 있으니 종료해 주세요.

## 모니터가 하는 일

보드는 키를 누를 때마다 아날로그 이벤트를 **스스로 올려보냅니다.** 이 앱은 그것을 듣기만
하며 보드에 **아무것도 쓰지 않습니다.** 설정이 바뀔 위험이 없습니다.

- 61키 전부, 0.02 mm 단위, 총 스트로크 4.00 mm
- 누름/뗌 방향 구분
- 키별 정지 상태 흔들림 폭 — 래피드 트리거 민감도의 실질적 하한입니다

## 프로토콜 요약

이 코드가 의존하는 사실들입니다. 전체 명세와 도출 과정은 `dev` 브랜치의
`docs/protocol.md` 에 있습니다.

### 전송 계층

| 항목 | 값 |
|------|-----|
| Vendor ID | `0x19F5` |
| Product ID | `0xFE20` / `0xFED0` / `0xFEB1` |
| USB 인터페이스 | `MI_01` |
| 통신 | OUTPUT / INPUT 리포트, 65바이트, 리포트 ID 0 |

### 아날로그 키 이벤트

보드가 비동기로 올려보내는 `0xa0` 리포트입니다. 16비트 필드는 빅엔디언입니다.

| 오프셋 | 의미 |
|--------|------|
| `[0]` | `0xa0` 이벤트 마커 |
| `[3]` | 키 HID usage. 수정자는 `0x00`, Fn 은 `0x01` |
| `[7]` | **깊이, 0.02 mm 카운트** (0 = 안 눌림, 200 = 바닥) |
| `[9]` | 방향: `0x01` 누름, `0xff` 뗌 |
| `[12..13]` | 키별 센서값 (고유하지 않음) |
| `[14..15]` | 총 스트로크 = 200 카운트 = 4.00 mm |
| `[16..17]` | 현재 ADC |
| `[18..19]` | 키별 기준 ADC |

HID 는 수정자를 키코드가 아니라 비트마스크로 보고하므로, 수정자 7개와 Fn 은 `[3]` 이
자리표시자입니다. 이들은 `[12..13]` 과 `[18..19]` 의 조합으로 식별하며, 측정값이
`src/keyboard/fingerprints.ts` 에 들어 있습니다.

보드에서 **재캘리브레이션을 하면 기준 ADC 가 바뀌어** 이 8개 키의 식별이 어긋날 수
있습니다. 그 경우 `dev` 브랜치의 이벤트 탭에서 다시 연결한 뒤 표를 갱신하면 됩니다.

## 구조

```
src/
  hid/         WebHID 전송 계층 — 장치 핸들, 리포트 길이, 요청/응답 대응, 트래픽 로그
  protocol/    패킷 프레임, 이벤트 디코더, 코덱 인터페이스
  keyboard/    Raven61 61키 배열과 수정자 식별표
  state/       연결·선택·식별 스토어
  tools/       장치 연결 UI
  features/    모니터
```

기능 패널은 `Raven61Codec` 인터페이스(`src/protocol/codec.ts`)에 물려 있습니다. 코덱이
구현한 메서드만큼 UI 가 켜지므로, 프로토콜이 더 해독되면 패널이 하나씩 열립니다.

## 라이선스

Apache-2.0. 자기 소유 기기의 상호운용성 확보를 위한 프로젝트이며, 순정 드라이버의 코드나
바이너리는 포함하지 않습니다.
